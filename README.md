# Taame

A recommendation engine for film, television and books that runs entirely
on your phone. No account, no server, nothing to sign up for.

This repo holds Taame's releases for Android. The source code is private.

## Install

Taame needs Android 7 or newer.

1. On your phone, open this link. It is always the newest version:
   https://github.com/georges-fd/taame-releases/releases/latest/download/taame.apk
2. Your browser asks to allow installing apps. Allow it, one time.
3. Open Taame. It asks to let it update itself: tap "Continue", turn on
   "Allow from this source", and come back.

What changed in each version: [CHANGELOG.md](CHANGELOG.md)
